## 📌 Sobre o Projeto

Este repositório contém um projeto desenvolvido com o objetivo de consolidar e aplicar os fundamentos da **Programação Orientada a Objetos (POO)** utilizando Python.

A aplicação simula um sistema de gerenciamento de biblioteca, reproduzindo operações comuns desse ambiente, como cadastro de livros e usuários, gerenciamento de empréstimos e controle de disponibilidade do acervo.

O projeto foi desenvolvido como exercício prático de aprendizagem, com foco na organização do código, reutilização de componentes e aplicação dos principais conceitos da programação orientada a objetos.

## 🎯 Objetivos

- Compreender e aplicar os fundamentos da Programação Orientada a Objetos.
- Desenvolver classes e estabelecer relações entre objetos.
- Praticar os conceitos de herança, encapsulamento e polimorfismo.
- Trabalhar com modularização e organização do código.
- Desenvolver uma aplicação estruturada, reutilizável e de fácil manutenção.

## 🧠 Conceitos de POO Aplicados

| Conceito | Aplicação no Projeto |
|---|---|
| **Classes e Objetos** | Representação de entidades como livros, usuários e biblioteca. |
| **Encapsulamento** | Organização e controle do acesso aos atributos e métodos dos objetos. |
| **Herança** | Reutilização e extensão de características entre classes. |
| **Polimorfismo** | Possibilidade de implementar comportamentos específicos em diferentes classes. |
| **Abstração** | Representação das características essenciais das entidades do sistema. |

## ⚙️ Funcionalidades

O sistema simula operações básicas de gerenciamento de uma biblioteca:

- 📖 Cadastro e gerenciamento de livros.
- 👤 Cadastro e gerenciamento de usuários.
- 🔄 Registro de empréstimos e devoluções.
- 📦 Controle de disponibilidade dos livros.

## 🚀 Como Executar

### Pré-requisitos

- Python 3.x instalado.
- Git instalado (opcional, para clonar o repositório).

### Instalação

**1. Clone o repositório:**

```bash
git clone <URL_DO_REPOSITORIO>
```

**2. Acesse a pasta do projeto:**

```bash
cd OOP_PYTHON
```

**3. Execute a aplicação:**

```bash
python main.py
```
